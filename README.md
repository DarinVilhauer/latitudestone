# Latitude Stone Website

This package is ready for GitHub Pages. Upload every item in this folder—including the `assets` folder—to the root of the `latitudestone` repository.

## Publish
1. Commit the uploaded files to `main`.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, `main`, and `/(root)`.
4. Wait for the Pages deployment to finish, then hard-refresh the site.

## Before public launch
- Confirm final email address and contact destination.
- Add TREC IABS and Consumer Protection Notice links.
- Replace provisional insight titles/dates as real content is published.
- Confirm all final service language.
